AnomInsight — design directions

Four versions of the same product, same content and same business goals. Open each in turn and compare; none of them replaces the others.

  • Original The site as it existed before this work An exact copy of index01.html / style01.css / js/* as they existed on disk before this redesign — same content, same behaviour, same files, only relocated (relative asset paths adjusted; nothing else changed). The live src/frontend/index01.html itself was never touched either. Kept forever unchanged as the baseline reference.
  • Version A Same site, redesigned from the ground up Same content, information architecture, messaging, brand identity and the protected portfolio deck as the Original — rethought visually: a real type/spacing scale, Problem and Solution merged into one composition instead of two near-identical icon grids, a "Measured results" band pulled up near the top, a founder section, and the closing roadmap/audit/contact sequence returned to normal scroll instead of a 190vh scroll-jacked stack. Still Manrope + Source Sans 3, still the warm dark/amber identity.
  • Version B The Audit Dossier Light paper and graphite ink, Archivo and Spectral, numbered chapters, ruled tables and lettered exhibits. One authored motion: a marker sweep across the measured figures.
  • Version C The Control Room Cool graphite console, Barlow Semi Condensed and Azeret Mono, a persistent nav rail and bordered modules with status LEDs. One authored motion: instrument initialisation.
Written up in docs/design-comparison.md. Product context and the facts every version has to stay true to are in docs/product-understanding.md.
