# AnomInsight Design System

## Brand

- Brand: AnomInsight
- Style: premium, minimal, technical, trustworthy, industrial
- Target audience: SMEs and industrial companies
- Avoid generic AI/startup aesthetics

## Protected Components

### Portfolio

The current Portfolio section is approved.

DO NOT:
- substantially redesign the layout
- change the project presentation
- replace the existing visual structure
- introduce unrelated visual patterns

ALLOWED:
- responsive improvements
- accessibility improvements
- bug fixes
- performance improvements
- minor spacing adjustments when technically necessary

## Controlled Components

- Typography
- Color palette

These may be improved, but should remain consistent with the existing
AnomInsight visual identity.

## Creative Areas

The following areas can be redesigned or improved freely:

- Hero
- Services
- About
- Contact
- Page transitions
- Micro-interactions
- Supporting visual elements
- General component styling
- Navigation
- Buttons

The AI should make design decisions based on usability, hierarchy,
brand consistency and modern B2B design principles.

## General Principles

- Avoid unnecessary redesigns.
- Do not change something simply for novelty.
- Prefer simplicity over visual noise.
- Avoid excessive gradients, glassmorphism, rounded cards and decorative elements.
- Maintain strong typography and spacing hierarchy.
- Animations should have a functional or communicative purpose.
