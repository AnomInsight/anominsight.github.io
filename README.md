# AnomInsight Website

AnomInsight is a founder-led data analytics practice. This website introduces the services, showcases project examples, and gives potential clients a way to get in touch or book a free discovery call.

## What is here

* The files in the project root make up the current Coming Soon page published at the main website address.
* The full English and Hungarian website is in `src/frontend/versions/a/`. It includes the homepage, services, project examples, and contact form.
* Shared translations and project details are stored in `src/frontend/shared/`.

## How it is built

The website uses standard HTML, CSS, and JavaScript. There is no build step or package installation required; the files can be served directly as a static website.

The site is currently hosted on GitHub Pages.

## Preview the main website

To preview the main website locally, open:

* `src/frontend/versions/a/index.html` — homepage
* `src/frontend/versions/a/services.html` — services page

Because these pages depend on shared files and assets elsewhere in the repository, using a local web server is recommended instead of opening the HTML files directly in a browser.
